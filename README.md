# AKT TRACKER

AKT TRACKER is a prototype Android application for investigating suspicious scam activity and tracing suspicious digital routes using an authorized, privacy-aware workflow.

The project is intended for security teams, fraud investigators, or lawful digital forensic work. It is not designed for unauthorized surveillance or stalking.

## Features
- Incident intake for suspicious scam reports
- Network route snapshot for suspicious contacts or domains
- Location and communication event tracking with consent-based workflows
- Incident timeline and evidence checklist
- Safe review workflows for forensic investigation

## Architecture
- Kotlin Android app
- Material 3 interface
- Local data model for investigation records
- Network and route analysis extension points

## Ethical use notice
This app is meant to support legitimate investigations, compliance work, and authorized digital security analysis. Do not use it to monitor individuals without lawful basis or consent.

## Getting started
1. Open the project in Android Studio.
2. Install Android SDK 34 or newer.
3. Sync Gradle.
4. Run the app on a device or emulator.
